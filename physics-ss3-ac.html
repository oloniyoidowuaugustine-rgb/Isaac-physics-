Topic: Alternating Current (AC)

1. Definition

Alternating current (AC) is an electric current that changes direction periodically.

2. Direct Current (DC)

Direct current flows in one direction only (e.g., batteries).

3. AC Voltage Equation

V = V₀ sin(ωt)

V₀ = peak voltage
ω = angular frequency
t = time

4. RMS Values

V_rms = V₀ / √2
I_rms = I₀ / √2

5. Frequency

f = 1 / T

In Nigeria, standard AC frequency is 50 Hz.

6. Advantages of AC

  • Can be transmitted over long distances
  • Voltage can be stepped up or down using transformers
  • More economical for power distribution

7. Example

Example: If peak voltage V₀ = 220V V_rms = 220 / √2 ≈ 155.6V

8. Notes

  • AC waveform is sinusoidal.
  • RMS value is the effective voltage.
  • Household electricity supply is AC.
