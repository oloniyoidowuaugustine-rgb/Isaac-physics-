Topic: Reflection by Curved Mirrors

1. Definition

Curved mirrors are mirrors with **spherical surfaces** that reflect light to form images. There are two types:

  • Concave mirrors – inward curved
  • Convex mirrors – outward curved

2. Mirror Formula

1/f = 1/u + 1/v

Where:
f = focal length
u = object distance
v = image distance

3. Magnification

m = h' / h = -v / u

h = object height, h' = image height

4. Ray Diagrams

  • Concave mirrors can produce real or virtual images depending on object position
  • Convex mirrors always produce virtual, diminished images
  • Principal rays: parallel → focus, through center → same line, focus → parallel

5. Examples

Example 1: An object is placed 20 cm in front of a concave mirror of focal length 10 cm. Using mirror formula: 1/f = 1/u + 1/v → 1/10 = 1/20 + 1/v → 1/v = 1/10 - 1/20 = 1/20 → v = 20 cm Image is real and inverted
Example 2: A car rearview mirror (convex) forms virtual images behind the mirror. Objects appear smaller and farther away.

6. Notes

  • Focal length is positive for concave, negative for convex (sign convention).
  • Concave mirrors can magnify images; convex mirrors always reduce image size.
